# 教学评价助手

登录后从侧栏进入「教学评价助手」，刷新学校评价列表，勾选待评价课程，再读取问卷并配置各项选项和评语。检查配置后会展示本次所选课程数量、评分与文字评价，确认后逐门提交；处理过程中可在当前课程结束后停止。

每门课程提交前都会重新读取评价列表和问卷，使用该课程最新的隐藏字段。不同问卷结构、重复教师课程记录、服务器未确认完成或网络失败都会停止处理，不自动重发评价 POST。完成状态来自学校评价列表，重定向和 HTTP 202 不会直接被当作已评价。

教务仅支持 HTTP。油猴脚本在教务页面上下文中请求并共享验证码与登录 Cookie；登录及评价 POST 使用手动重定向，随后通过已知 HTTP 入口核对状态，避免原站返回 HTTPS 跳转地址后报错。

## 验证

在 `web` 目录运行 `npm test`，覆盖同源 HTTP 请求、登录重定向与失败判定、提交不重放，以及评价配置、GBK 编码、问卷结构和重复记录检查。`npm run build` 和 `npm run build:userscript` 分别构建网页与油猴版本。

已安装 Playwright 和 Microsoft Edge 时，可先构建油猴版本，再运行 `npm run test:browser`。如果 Playwright 位于其他目录，通过环境变量 `PLAYWRIGHT_MODULE_PATH` 指定模块路径。测试使用独立无头浏览器，拦截全部请求并模拟学校列表和问卷，验证预览不提交、隐藏字段刷新、中文表单编码、单次提交、HTTPS 重定向阻止与失败停止，不使用真实账号或访问真实教务服务器。

真实环境中需要学校开放评价并返回待评价课程，才能读取真实问卷和进行提交；空列表不代表已经完成全部教学评价。不要将模拟问卷测试结果作为真实提交记录。
