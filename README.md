# BetterHRBUST

自制的哈尔滨理工大学教务在线网页客户端。

教务在线（`http://jwzx.hrbust.edu.cn/academic/`）是清华教育在线 / 优慕课 URP
架构的老式 JSP 应用：无官方 API、无文档、页面编码不统一、真实接口地址藏在
模块调度器后面。要用它做现代前端，第一步不是写页面，而是**把接口摸清楚**。

```
BetterHRBUST/
├── docs/api/        接口文档（13 篇，手写，面向开发者）
├── tools/probe/     探测工具（零依赖 Node CLI + 网页控制台）
└── web/             网页客户端（下一阶段）
```

## 路线图

### 阶段一：接口探测与文档 ✅

用真实账号对教务系统做了自动化探测：**89 个接口，58 个拿到业务数据**，
覆盖成绩、课表、培养方案、考试、学籍、教室、公告等 11 个功能域。

成果：

- [`docs/api/`](./docs/api/) —— 13 篇手写接口文档，含请求参数、响应结构、
  解析要点与踩坑记录，可直接指导前端开发
- [`tools/probe/`](./tools/probe/) —— 可复用的探测工具，教务系统改版后
  重跑一次即可重新验证全部路径

### 阶段二：网页客户端 🚧

基于上述文档搭建替代教务在线原界面的 Web 应用。规划中的功能
（均已有实测接口支撑）：

| 功能 | 依赖接口 | 说明 |
| --- | --- | --- |
| 登录与验证码 | `getCaptcha.do`、`j_acegi_security_check` | 会话托管，支持会话过期自动重登 |
| 课程表 | `showTimetable.do` | 周次切换、单双周、ICS 日历导出 |
| 成绩查询 | `studentOwnScore.do` | 分学期展示、GPA 计算、按学期/属性筛选 |
| **学分完成度** | 培养方案 + 成绩 | 课组学分要求 vs 实际获得，毕业进度可视化 |
| 考试安排 | `studentQueryAllExam.do` | 倒计时、添加到日历 |
| 空教室查询 | `roomschedule*.jsdo` | 按周推算连续空档，自习/活动选座 |
| 公告与校历 | `viewCalendarInfo.do`、`calendarViewList.do` | 周次公告、真实开学日期 |
| 个人信息 | `showPersonalInfo.do` 等 | 敏感字段默认脱敏展示 |

## 接口文档

从 [`docs/api/README.md`](./docs/api/README.md) 进入。若只读一篇，读
[`00-overview.md`](./docs/api/00-overview.md)——里面有四个动手前必须知道的事实：

1. **编码不统一**：成绩是 UTF-8，课表/菜单是 GBK，必须按响应头判断；
2. **路径猜不出来**：菜单只给 `moduleId`，真实地址要靠 `accessModule.do` 调度揭示；
3. **会话失效不返回 401**：而是返回登录页 HTML，且要看成规模的回落；
4. **上下文 ID 不是学号**：课表等接口用的是教务内部 ID。

## 探测工具

开发期的接口验证工具，也是教务系统改版后的维护手段：

```bash
# 网页控制台（推荐）：浏览器里登录，服务端持有会话
node tools/probe/server.mjs --open

# 命令行
node tools/probe/probe.mjs --user 学号
```

自动完成：验证码登录 → 门户页多层抓取 → 模块调度发现 → 多轮递进探测 →
参数收割带参补测 → 样本结构分析 → 产物脱敏落盘。

| 特性 | 说明 |
| --- | --- |
| 模块调度发现 | 跟随 `accessModule.do` 的 302 揭示真实功能页地址 |
| 多轮递进 | 每轮从已落盘样本里挖新地址，直到收敛（实测 3 轮） |
| 参数收割 | 提取 `cid`/`userid`/`scoreid`/加密 `studentId`，带参补测缺参接口 |
| 产物脱敏 | 落盘前屏蔽学号、姓名、班级、证件号、手机号、加密串（默认开启） |
| 目录保护 | 拒绝把输出目录指向 `docs/`，探测永远不会改动接口文档 |

零第三方依赖，Node ≥ 18。详见 [`tools/probe/README.md`](./tools/probe/README.md)。

## 隐私与合规

- **探测产物不含隐私数据**：学号、姓名、班级、证件号、手机号、加密串在落盘前
  统一脱敏，照片等二进制内容不落盘。`manifest.json` 的 `redaction` 字段
  记录每次运行的脱敏统计。
- `tools/probe/output/` 已配置 gitignore；其中 `session.json` 是会话凭证文件，请勿分享。
- 选课、退课、保存学籍等**会改变教务数据**的操作不在本项目范围内——
  网页客户端只做查询与展示，写操作引导回教务系统原生界面。
- 请求保持串行、对静态数据做本地缓存，不给教务系统增加额外压力。

## 环境要求

- Node.js ≥ 18（探测工具；网页客户端另行说明）
- 校园网或学校 VPN（访问教务系统）
